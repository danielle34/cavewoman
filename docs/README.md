# Project site

Single-page CAVEWOMAN site, built on the Nerfies template (CC BY-SA 4.0).

```
docs/
  index.html
  emnlp_2026_logo_v1.png
  .nojekyll
  static/{css,js,images}/
```

Preview locally:

```bash
cd docs && python3 -m http.server 8000
```

CDN dependencies: Bulma 0.9.4, Font Awesome 5.15.4, Academic Icons,
Google Fonts.

Template: [Nerfies](https://github.com/nerfies/nerfies.github.io) under
[CC BY-SA 4.0](http://creativecommons.org/licenses/by-sa/4.0/). The page
inherits the same license.
